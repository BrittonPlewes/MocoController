# MocoController GUI

A PyQt gui for controlling a diy [grblHAL](https://github.com/grblHAL) driven motion control rig by converting animation software curve data into gcode.

## Basic Usage

Natively reads .xaf files, an xml formatted filetype generated by 3dsmax used specifically for exporting animation bezier curves. These bezier curves can be converted to gcode instructions, which can be streamed directly to the microcontroller over serial. 

Curve -> gcode instructions can be a linear conversion, or go through an intermediate bezier curve similar to maya driven keys. This works great for converting a distance to the corresponding focal ring rotation, where the conversion cannot be defined mathematically and must be calibrated manually.

Currently hard-coded for a 5 axis controller, tested with a [Teensy 4.2](https://www.pjrc.com/store/teensy41.html). Future plans are to have a dynamic axis count, either by using an STM32 controller or multiple synced Teensys.
