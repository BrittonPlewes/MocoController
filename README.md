# MocoController GUI

A PyQt5 gui for controlling a dyi [grblHAL](https://github.com/grblHAL) driven motion control rig.

## Basic Usage

Natively reads .xaf files, an xml formatted filetype generated by 3dsmax used specifically for exporting animation controller bezier curves

Currently hard-coded for a 5 axis controller, tested with a [Teensy 4.2](https://www.pjrc.com/store/teensy41.html). Future plans are to have a dynamic axis count, either by using an STM32 controller or multiple synced Teensys.

Also hosts a mobile website on local IP port 8080 to act as a pendant jog controller with live axis readout, similar to UGS's pendant mode.
